---
title: 2D games
description: Build a 2D physics scene with Workspace, World2D, and Part2D.
---

Kinemium uses the same Workspace for 2D and 3D games. Set its dimension to D2 to render a 2D scene and simulate bodies independently of the frame rate.

## Create a scene

```lua
workspace.Dimension = Enum.Dimension.D2
local physics = game:GetService("Workspace2D")
physics.Gravity = Vector2.new(0, 250)

local level = Instance.new("World2D", workspace)

local floor = Instance.new("Part2D", level)
floor.Size = UDim2.fromOffset(600, 40)
floor.Position = UDim2.fromOffset(0, 400)
floor.BackgroundColor3 = Color3.fromRGB(90, 150, 100)

local ball = Instance.new("Part2D", level)
ball.Size = UDim2.fromOffset(40, 40)
ball.AnchorPoint = Vector2.new(0.5, 0.5)
ball.Position = UDim2.fromOffset(300, 100)
ball.Anchored = false
ball.IsBall = true
ball.Elasticity = 0.7
ball.BackgroundColor3 = Color3.fromRGB(220, 120, 60)
```

The ball falls onto the floor and bounces. Positive Y points down.

## Move dynamic objects

```lua
ball.Velocity = Vector2.new(60, 0)
ball:ApplyImpulse(Vector2.new(0, -150))
```

Read the position, rotation, and velocity during a RunService event. The position retains its scale components, so use AbsolutePosition for the resolved top-left position.

## Group objects

Use Folder for organization, World2D to enable or disable a scene, and RigidBody2D to keep multiple physics parts together.

```lua
local crate = Instance.new("RigidBody2D", level)
for i = 1, 2 do
    local piece = Instance.new("Part2D", crate)
    piece.Size = UDim2.fromOffset(24, 24)
    piece.Position = UDim2.fromOffset(100 + i * 24, 80)
    piece.Anchored = false
end
```

## Query and pause

```lua
local hit = physics:Raycast(Vector2.new(200, 0), Vector2.new(0, 500))
if hit then
    print(hit.Instance.Name)
end

workspace.SimulatePhysics = false
-- The scene is still visible.
workspace.SimulatePhysics = true
```

Switch to D3 to stop 2D simulation and restore 3D rendering. Regular GUI elements still work in both modes. The two physics worlds do not interact.

Prefer offset-based positions and sizes for gameplay geometry. Scaled UDim2 properties depend on the logical viewport, which may vary across clients.

In Studio, hold the middle mouse button and drag inside the 2D viewport to move around the scene. The grid moves with the scene, so you can reach objects beyond the viewport edges.

## Simple 2D objects

You don't need separate rigid-body classes for floors, physics objects, and moving platforms. Use Part2D and change `Anchored`:

```lua
local floor = Instance.new("Part2D", workspace) -- Anchored defaults to true
local ball = Instance.new("Part2D", workspace)
ball.Anchored = false
ball.IsBall = true
```

For artwork use Sprite2D, which also handles sprite-sheet playback. Use Shape2D for custom lines or polygons, Trigger2D to detect touching parts, Attachment2D for markers, Camera2D for the view, and CharacterController2D for script-controlled player motion. Use Folder or RigidBody2D to group objects.

For raycasts, use `game:GetService("Workspace2D"):Raycast(origin, direction)` rather than creating an extra node.
