## How to read these

Start with the getting started guide if you haven't run the engine yet. After that, read whichever guide matches the system you're building, then use the reference pages for exact member behavior.

The engine is under active development. Some APIs are placeholders, and a few properties are accepted but do nothing. The guides call those out where they matter, and the reference pages mark them individually. When behavior matters to your game, check the reference page before you rely on it.

## Before you build

You need the engine itself, a text editor for Luau, and a way to run a client and a server when you test networking. The editor can run a standalone session for singleplayer work, which also exercises both sides in one process.
