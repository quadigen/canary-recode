Datatypes are value types. You create them with a constructor such as `Vector3.new()`, pass them to properties and methods, and compare them by value. Most are immutable: read a field, derive a new value, and assign it back.

```lua
local size = Vector3.new(4, 1, 2)
local half = size / 2
print(half) -- 2, 0.5, 1
```

The pages in this section group related types. Every datatype installed as a Luau global is listed below.

## Common behavior

- Constructors reject arguments of the wrong type and raise an error instead of returning `nil`.
- `==` compares values, not identity. Two separately constructed values with the same components are equal.
- `tostring()` returns a readable form, which is useful in logs but not a serialization format.
- Members marked read-only return a new value or a copy. Assigning to them raises an error.
- Optional constructor arguments default to zero unless the type page says otherwise. `Quaternion` defaults `w` to `1`, and `TweenInfo` has its own defaults.
