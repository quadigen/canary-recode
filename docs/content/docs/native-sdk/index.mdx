The unified Kinemium Native SDK has **one C API and two ways to use it**.

| Mode | Entry point | Context |
| --- | --- | --- |
| **Embedding** | Kinemium_CreateWithMode() | Your application owns an engine |
| **Native plugins** | Kinemium_PluginEntry() | The plugin borrows an existing engine context |

Both modes use the **same functions, types, handle validation and engine registries**, without separate KNE host tables.

Include **include/kinemium.h**, and for native plugin entry-point helpers, also **include/kinemium_plugin.h**. Unified SDK ABI: **2.0**.

The unified Native SDK is the public interface for embedding and plugin authoring. The KNE 3.x runtime supports legacy plugins; see the [legacy documentation](/docs/kne) for its API.

Linux embedding, native plugin lifecycle, classes, services, datatypes, signals, and callbacks have integration tests. Editor executable linking and Windows/macOS packaging still require additional validation.
