---
title: Sky
description: Set a custom skybox using six square images.
---

Use `Sky` to surround a 3D scene with a cubemap. Supply an image for each direction, such as six faces exported from an environment texture.

## Getting started

```lua
local sky = Instance.new("Sky", game:GetService("Lighting"))
sky.SkyboxRt = "right.png"
sky.SkyboxLf = "left.png"
sky.SkyboxUp = "up.png"
sky.SkyboxDn = "down.png"
sky.SkyboxBk = "back.png"
sky.SkyboxFt = "front.png"
```

All six images must be available to the game, square, the same dimensions, and no larger than 4096 × 4096 pixels. If the cubemap cannot load, the scene falls back to the procedural sky. Web builds currently use that fallback.

## Properties

All properties are read-write.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `SkyboxRt` | string | "" | Right face image. |
| `SkyboxLf` | string | "" | Left face image. |
| `SkyboxUp` | string | "" | Top face image. |
| `SkyboxDn` | string | "" | Bottom face image. |
| `SkyboxBk` | string | "" | Back face image. |
| `SkyboxFt` | string | "" | Front face image. |
| `CelestialBodiesShown` | boolean | true | Controls whether celestial bodies are shown. |
| `SunTextureId` | string | "" | Custom sun image reference. |
| `MoonTextureId` | string | "" | Custom moon image reference. |
| `SunAngularSize` | number | 21 | Sun angular size, clamped to 0–360. |
| `MoonAngularSize` | number | 11 | Moon angular size, clamped to 0–360. |
| `StarCount` | number | 3000 | Star count, clamped to 0–5000 and stored as an integer. |
| `SkyboxOrientation` | Vector3 | (0, 0, 0) | Skybox orientation. |

The custom sun and moon images, angular sizes, star count and orientation can be stored, but their visual effects aren't fully supported yet. Don't depend on them to produce a specific appearance.

## Procedural sky and distance fog

When no valid custom skybox can be loaded, Kinemium draws a procedural sky with daylight colors, a horizon, and a nighttime appearance.

The scene also supports distance fog that follows the sky and sunlight. If you've explicitly configured fog, those settings take priority. See [Lighting](/docs/services/Lighting) for the scene's time of day and lighting controls.
