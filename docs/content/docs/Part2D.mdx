---
title: Part2D
description: Create a visible box or circular physics body in a 2D scene.
---

`Part2D` is a 2D physics object that uses the familiar `GuiObject` layout and appearance properties. Use the usual `Position`, `Size`, `AnchorPoint`, `Rotation`, and `BackgroundColor3` properties to lay out your scene.

## Getting started

```lua
workspace.Dimension = Enum.Dimension.D2

local ball = Instance.new("Part2D", workspace)
ball.Size = UDim2.fromOffset(32, 32)
ball.Position = UDim2.fromOffset(120, 40)
ball.IsBall = true
ball.Anchored = false
ball.BackgroundColor3 = Color3.fromRGB(255, 140, 60)
ball.Velocity = Vector2.new(100, 0)
```

Parent parts to Workspace directly, or use a `World2D`, `Folder`, or `RigidBody2D` container. The older Workspace2D parenting convention still works in D2 mode. Positive Y points down.

## Properties

| Property | Type | Access | Default | Description |
| --- | --- | --- | --- | --- |
| `Anchored` | boolean | Read/write | true | Keeps the body static. |
| `CanCollide` | boolean | Read/write | true | Controls collision response. |
| `IsBall` | boolean | Read/write | false | Uses a circular shape with diameter equal to the shorter size dimension. |
| `Density` | number | Read/write | 1 | Material density, clamped at zero. |
| `Friction` | number | Read/write | 0.3 | Surface friction, clamped at zero. |
| `Elasticity` | number | Read/write | 0 | Bounce coefficient, clamped between zero and one. |
| `Velocity` | Vector2 | Read/write | Vector2.new(0, 0) | Linear velocity in logical pixels per second. |
| `VelocityX` | number | Read/write | 0 | X component of Velocity. |
| `VelocityY` | number | Read/write | 0 | Y component of Velocity. |
| `AngularVelocity` | number | Read/write | 0 | Angular velocity in degrees per second. |

Position, size, rotation, and physical material changes synchronize on the next update. Physics updates the position offsets without discarding the scale components or anchor point.

## Methods

### ApplyImpulse

```lua
ApplyImpulse(impulse: Vector2): ()
```

Queues a linear impulse for the next physics step, in mass times logical pixels per second. It has no effect on an anchored part.

```lua
ball:ApplyImpulse(Vector2.new(0, -120))
```

### ApplyAngularImpulse

```lua
ApplyAngularImpulse(impulse: number): ()
```

Queues a rotational impulse in mass times squared logical pixels per second. Positive values rotate clockwise on screen.

## Notes

- 2D parts do not collide with 3D geometry.
- Destroying a part removes its body. Detaching it removes its body on the next update.
- Use offset-based sizes for consistent physical dimensions across displays.
- Use a RigidBody2D container for compound objects rather than nesting physics bodies inside GUI objects.
