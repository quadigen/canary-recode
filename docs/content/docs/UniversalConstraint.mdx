---
title: UniversalConstraint
description: Join two attachments while allowing rotation about two axes.
---

Use `UniversalConstraint` for a joint that bends in two directions, such as a vehicle coupling.

## Getting started

This example assumes `partA` and `partB` are existing parts in Workspace, with `attachmentA` and `attachmentB` parented to them respectively.

```lua
local constraint = Instance.new("UniversalConstraint", partA)
constraint.Attachment0 = attachmentA
constraint.Attachment1 = attachmentB
constraint.LimitsEnabled = true
constraint.MaxAngle = 35
```

## Properties

All properties below are read/write. See [Constraint](/docs/Constraint) for the shared attachment and activation properties.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `LimitsEnabled` | `boolean` | `false` | Enables angular limits. |
| `MaxAngle` | `number` | `45` | Approximate angular bound in degrees. |
| `Radius` | `number` | `0.1` | Compatibility property. |
| `Restitution` | `number` | `0` | Stored but not applied to joint motion. |

## Notes

`MaxAngle` accepts 0–180 degrees, `Radius` must be nonnegative, and `Restitution` accepts 0–1. Values outside these ranges raise an error. The angular bounds are approximate. Changing `Restitution` doesn't change how the joint rebounds.
