---
title: MeshPart
description: Use an imported mesh as a part, with its own texture and collision fidelity.
---

`MeshPart` is a `Part` whose visible geometry comes from a mesh asset instead of a primitive shape. Everything from `Part` still applies: it collides, casts shadows, can be anchored, and participates in physics.

## Getting started

```lua
local meshPart = Instance.new("MeshPart")
meshPart.MeshId = "models/crate.glb"
meshPart.TextureId = "textures/crate.png"
meshPart.Position = Vector3.new(0, 3, 0)
meshPart.Anchored = true
meshPart.Parent = game:GetService("Workspace")
```

The part's `Size` still defines its physics box. The mesh is visual geometry unless you choose a collision fidelity that uses it.

## Properties

| Property | Type | Access | Default | Description |
| --- | --- | --- | --- | --- |
| `MeshId` | `string` | Read/write | `""` | Asset path of the mesh. Assigning it clears inline mesh content. |
| `MeshIndex` | `number` | Read/write | `0` | Index of the mesh inside a multi-mesh asset. Negative values are ignored. |
| `MeshContent` | `Content` | Read/write | Empty | Inline mesh content, used instead of an asset path. |
| `TextureId` | `string` | Read/write | `""` | Asset path of the texture. `TextureID` is an alias. |
| `CollisionFidelity` | `Enum.CollisionFidelity` | Read/write | `Default` | How closely the collision shape follows the mesh. |
| `RenderFidelity` | `Enum.RenderFidelity` | Read/write | `Automatic` | How aggressively the mesh is simplified for rendering. |

These come on top of every `Part` property, so `Size`, `CFrame`, `Anchored`, `CanCollide`, `Color`, and the rest behave the same way.

### Mesh sources

A mesh can come from an asset path or from inline content, not both. Setting `MeshId` clears `MeshContent`, and setting `MeshContent` takes precedence while it's present.

```lua
meshPart.MeshId = ""
meshPart.MeshContent = someContent
```

`MeshIndex` picks one mesh out of an asset that contains several. Assigning a negative or non-numeric index is ignored, and the previous index stays.

### Collision fidelity

`CollisionFidelity` decides whether the part collides as its box or as its mesh:

- `Default` uses the engine's default for the asset.
- Other values trade accuracy for cost. More accurate collision means more triangles to test.

Changing fidelity rebuilds the part's collision geometry, so set it when you create the part rather than every frame.

## Methods

| Signature | Description |
| --- | --- |
| `GetMeshContent(): Content` | Returns the inline mesh content. |
| `SetMeshContent(content: Content): ()` | Replaces the inline mesh content. |
| `GetBoneNames(): {string}` | Returns the bone names of a rigged mesh, or an empty table for a static mesh. |
| `GetBoneWorldCFrame(boneName: string): CFrame?` | Returns the bone's world-space CFrame, or `nil` if the bone does not exist. |
| `GetBoneTransform(boneName: string): CFrame?` | Returns the bone's local transform, relative to its parent bone. |
| `SetBoneTransform(boneName: string, transform: CFrame): ()` | Sets a bone's local transform. |
| `GetBoneBindTransform(boneName: string): CFrame?` | Returns the imported rest transform in parent space. |
| `SetBoneTransforms(transforms: {[string]: CFrame}): boolean` | Applies multiple local transforms together. Returns whether the pose was applied. |
| `GetBoneParent(boneName: string): string?` | Returns the parent bone's name, or `nil` for a root bone or unknown bone. |
| `GetAnimationClips(): {{ Index: number, Name: string, Length: number }}` | Returns the clips imported with the mesh. `Length` is in seconds. |

`ApplyImpulse()` and the CSG methods from `Part` are also available.

```lua
for _, clip in meshPart:GetAnimationClips() do
	print(clip.Name, clip.Length)
end
```

Use `GetAnimationClips()` to build an `Animation` for a rigid rig: set `Animation.ClipName` to a returned `Name`, then load it through an `Animator` parented under the part.

```lua
local content = meshPart:GetMeshContent()
```

### Bone transforms

`GetBoneTransform()` and `SetBoneTransform()` work in the bone's parent space. Moving one bone moves its children with it, and a root bone uses the mesh's own space. `GetBoneWorldCFrame(name)` reads the rendered pose in world space, including during animation playback. Use `GetBoneWorldCFrames()` to get a table of those transforms keyed by bone name.

```lua
local head = meshPart:GetBoneParent("Neck")
local world = meshPart:GetBoneWorldCFrame("Head")

meshPart:SetBoneTransform("Head", meshPart:GetBoneTransform("Head") * CFrame.Angles(0, 0, math.rad(15)))
```

The bone transform and parent getters return `nil` when the bone does not exist or the mesh has no bones. `SetBoneTransform()` is ignored in those cases, and it is also ignored while an `Animator` owns the mesh, because the animator owns the pose.

Use the bind transform to apply an offset relative to the imported rest pose. `SetBoneTransforms()` takes a table keyed by bone names, with CFrame values in parent space. It returns false if a name or value is invalid, the mesh has no bones, or the pose cannot be applied. Bones not included in the table keep their current local transforms.

## UsePartColor

`UsePartColor` is only readable on `PartOperation`, which is a separate CSG class. A plain `MeshPart` reports `false` for it, so don't use it to decide whether a mesh takes the part's color.

## Notes

- Mesh assets load asynchronously. A part can exist and simulate before its mesh is ready, so don't measure or query the visual geometry immediately after assignment.
- `Size` and the mesh's authored dimensions can disagree. Scale the part, or the asset, deliberately; physics follows `Size`.
- Cloning copies the mesh path, index, texture, fidelity, and inline content, but loads its own resources when needed.
- A missing mesh asset still leaves a usable physics part.
