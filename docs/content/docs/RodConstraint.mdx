---
title: RodConstraint
description: Keep two attachments a fixed distance apart.
---

`RodConstraint` holds two attachments at a set distance. Unlike a weld, it doesn't lock their rotation: the parts can swing around each other while the rod length stays fixed. It's a good fit for hanging signs, chains, trailer hitches, and pendulum-like props.

`RodConstraint` inherits from `Constraint`, so it also has `Enabled`, `Active`, `Attachment0`, and `Attachment1`.

## Getting started

```lua
local rod = Instance.new("RodConstraint")
rod.Attachment0 = ceilingAttachment
rod.Attachment1 = signAttachment
rod.Length = 8
rod.Parent = model
```

At least one connected body must be dynamic, or there's nothing for the rod to pull.

## Properties

| Property | Type | Access | Default | Description |
| --- | --- | --- | --- | --- |
| `Length` | `number` | Read/write | `1` | Distance between the attachments, in studs. Must be at least `0`. |

`Length` accepts any value from `0` upward. Assigning a negative value raises an error. A length of `0` turns the rod into a point constraint that keeps the two attachment positions together without limiting rotation.

Changing `Length` rebuilds the joint, so the constraint can be briefly inactive while the new distance takes effect.

## Shared constraint properties

| Property | Type | Access | Default | Description |
| --- | --- | --- | --- | --- |
| `Enabled` | `boolean` | Read/write | `true` | Whether the joint is simulated. |
| `Active` | `boolean` | Read-only | `true` | Whether the joint currently has two resolvable ends. |
| `Attachment0` | `Attachment?` | Read/write | `nil` | First attachment. |
| `Attachment1` | `Attachment?` | Read/write | `nil` | Second attachment. |

`Active` is read-only. It becomes true after both attachments resolve to bodies and at least one is dynamic.

## Notes

- The constraint enforces a distance; it doesn't apply a spring. For flexible pulling, use `SpringConstraint` or `RopeConstraint`.
- Both attachments should be on different bodies for a useful rod. A rod between two anchors on the same body has no visible effect.
- Cloning copies the attachment references and `Length`, but the copy starts with no live joint.
- Destroying the constraint releases its physics joint.

## See also

- `Constraint` for the shared attachment behavior.
- `RopeConstraint` for a maximum distance with slack.
- `SpringConstraint` for springy connections.
