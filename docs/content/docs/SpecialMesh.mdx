Override the visual mesh of a part without changing its physics collider.

## Getting started

```lua
local mesh = Instance.new("SpecialMesh", part)
mesh.MeshType = Enum.MeshType.Sphere
mesh.Scale = Vector3.new(1, 2, 1)
```

## Properties

MeshType, MeshId, TextureId, Scale, Offset and VertexColor control rendering.

## Notes

File meshes use resolved local or embedded assets. Some legacy built-in mesh types use approximate primitive geometry. Missing assets retain their references.
