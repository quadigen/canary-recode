---
title: PlaneConstraint
description: Constrain relative translation to the plane of an attachment.
---

Use `PlaneConstraint` to keep one attachment on a plane defined by another, while allowing the connected objects to rotate.

## Getting started

This example assumes `partA` and `partB` are existing parts in Workspace, with `attachmentA` and `attachmentB` parented to them respectively.

```lua
local constraint = Instance.new("PlaneConstraint", partA)
constraint.Attachment0 = attachmentA
constraint.Attachment1 = attachmentB
```

## Properties

This class adds no properties of its own. See [Constraint](/docs/Constraint) for `Attachment0`, `Attachment1`, `Enabled` and `Active`.

## Notes

The first attachment's axis defines the plane normal. Movement within the plane and rotation remain free.
