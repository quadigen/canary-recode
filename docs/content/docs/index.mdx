Kinemium is a game engine with Luau scripting, a native editor, and support for standalone multiplayer games. This documentation has two halves: guides that walk you through building systems, and reference pages that describe every verified member of a class or service.

## Reference

The reference is organized by the object tree:

- **Classes** cover objects you create and parent, from `Part` and `Model` to `ScreenGui` and `ParticleEmitter`.
- **Services** cover the long-lived engine objects you get from `game:GetService()`, such as `Workspace`, `Players`, and `RunService`.

Each page documents the members that are actually exposed to Luau, including defaults, accepted types, and known placeholders. If a feature is incomplete, the page says so instead of describing behavior that isn't there.

## Status

The engine is under active development. Expect missing features and rough edges in both the engine and these docs. When an API matters to your game, check the reference page for its current limitations before you build around it.
