---
title: Actor
description: Groups scripts into a Parallel Luau execution domain and provides asynchronous message passing.
---

Use an `Actor` to group scripts that calculate results separately from updates to the world. Actors inherit from [Model](/docs/Model).

## Getting started

Place a Script inside an Actor. In that script, bind a topic before another script sends a message:

```lua
local actor = script:GetActor()
actor:BindToMessage("Update", function(value)
    actor:SetAttribute("Result", value * 2)
end)
```

From another script, call `actor:SendMessage("Update", 21)` with a reference to that Actor. The result is written asynchronously. See the [Parallel Luau guide](/docs/guides/parallel-luau) for execution phase restrictions.

## Methods

### SendMessage

```lua
SendMessage(topic: string, ...: any): ()
```

Schedules callbacks bound to the named topic on this Actor. Returns immediately. Unbound topics are ignored.

### BindToMessage

```lua
BindToMessage(topic: string, callback: (...any) -> ()): KinemiumConnection
```

Connects a message handler that starts in the serial phase. Must be called in serial execution by a script belonging to this Actor.

### BindToMessageParallel

```lua
BindToMessageParallel(topic: string, callback: (...any) -> ()): KinemiumConnection
```

Works like `BindToMessage()`, but callbacks begin in the parallel phase. Call `task.synchronize()` before changing ordinary instance properties.
