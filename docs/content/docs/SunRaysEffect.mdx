---
title: SunRaysEffect
description: Render volumetric sunlight shafts and drifting dust.
---

`SunRaysEffect` renders sunlight scattered by the air between the camera and the surfaces it sees. Opaque shadow-casting geometry shapes the shafts, so a window, arch, or skylight can carve a beam into the room. Dust motes drift through the scene and are visible where sunlight reaches them.

Parent the effect to `Lighting`. The default Lighting child starts disabled to avoid a costly full-screen raymarch and a separate shadow-depth pass. Enable it only for scenes that need sunlight shafts. The beam follows the sun direction from `ClockTime` or an authored `SunLightEffect` and fades with daylight.

```lua
local lighting = game:GetService("Lighting")
local rays = lighting:FindFirstChildOfClass("SunRaysEffect")
    or Instance.new("SunRaysEffect", lighting)

rays.Enabled = true
rays.Intensity = 0.55
rays.Spread = 0.8
rays.DustAmount = 0.7
rays.MaxDistance = 30
rays.SampleCount = 32
```

| Property | Default | Description |
| --- | --- | --- |
| `Enabled` | `true` | Enables the effect. |
| `Intensity` | `0.1` | Scattered light strength, from `0` to `1`. |
| `Spread` | `1` | Controls how visible the beam is from the side. Lower values concentrate scattering toward the sun. Range `0` to `1`. |
| `DustAmount` | `0.35` | Density variation and drifting motes, from `0` to `1`. The effect built into `Lighting` starts at `0`. |
| `MaxDistance` | `48` | Maximum distance from the camera sampled by the pass, from `4` to `128` studs. |
| `SampleCount` | `24` | Number of samples along each view ray, from `8` to `48`. Higher values make narrow shafts smoother and cost more GPU time. |

The last `SunRaysEffect` child of `Lighting` supplies the settings. Use the normal editor viewport or playtest to preview the effect. Keep `MaxDistance` sized to the space you want to light, since the sun occlusion map covers a local volume around the camera.
