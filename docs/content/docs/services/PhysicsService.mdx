---
title: PhysicsService
description: Register collision groups and configure which parts collide.
---

`PhysicsService` manages named collision groups and controls which groups of parts can collide. Assign a registered name to a part’s `CollisionGroup` property. Use `Workspace` for spatial queries.

## Getting started

```lua
local PhysicsService = game:GetService("PhysicsService")

PhysicsService:RegisterCollisionGroup("Players")
PhysicsService:RegisterCollisionGroup("NPCs")

print(PhysicsService:IsCollisionGroupRegistered("Players")) -- true
```

## Methods

### RegisterCollisionGroup

```lua
RegisterCollisionGroup(name: string): ()
```

Adds a collision group name to the service's list. Registering the same name twice is harmless; the duplicate is ignored. An empty name raises an error.

```lua
PhysicsService:RegisterCollisionGroup("Debris")
```

New groups collide with every group by default. You can register up to 32 groups, including `Default`.

### IsCollisionGroupRegistered

```lua
IsCollisionGroupRegistered(name: string): boolean
```

Returns `true` if the group name has been registered. `CollisionGroupExists()` is an alias with the same behavior.

```lua
if not PhysicsService:IsCollisionGroupRegistered("Players") then
    PhysicsService:RegisterCollisionGroup("Players")
end
```

### GetRegisteredCollisionGroups

```lua
GetRegisteredCollisionGroups(): {{name: string}}
```

Returns a one-based array of tables, each with a `name` field. The `Default` group is always present.

```lua
for _, group in PhysicsService:GetRegisteredCollisionGroups() do
    print(group.name)
end
```

### Collision filtering

| Signature | Description |
| --- | --- |
| `CollisionGroupSetCollidable(a: string, b: string, collidable: boolean): ()` | Enables or disables physical collisions between two registered groups. |
| `CollisionGroupsAreCollidable(a: string, b: string): boolean` | Reads the symmetric collision rule for two registered groups. |
| `GetMaxCollisionGroups(): number` | Returns the supported limit (32). |
| `RenameCollisionGroup(oldName: string, newName: string): ()` | Renames a group, updates assigned parts, and keeps the collision rules. |
| `UnregisterCollisionGroup(name: string): ()` | Removes a group and moves its assigned parts back to `Default`. |

```lua
local physics = game:GetService("PhysicsService")
physics:RegisterCollisionGroup("Ghosts")
physics:CollisionGroupSetCollidable("Ghosts", "Default", false)
part.CollisionGroup = "Ghosts"
```

The two group names must be registered before setting or reading a rule. `Default` can't be renamed or unregistered. These rules control rigid-body collisions; character-controller and deformable-body filtering and collision-group-aware spatial queries aren't covered by this implementation.

### Collision group predicates

These methods are exposed but don't implement collision filtering:

| Signature | Returns | Notes |
| --- | --- | --- |
| `IsCollisionGroupDefault(name: string)` | `boolean` | True only for `"Default"`. |
| `IsCollisionGroupDoesNotCollide(name: string)` | `boolean` | Always `false`. |
| `IsCollisionGroupNotCollide(name: string)` | `boolean` | Always `false`. Alias of the above. |
| `IsCollisionGroupNotCollideWith(name: string)` | `boolean` | Always `false`. Alias of the above. |

### Raycast and overlap placeholders

```lua
Raycast(origin: Vector3, direction: Vector3, params: any?): {}
RaycastParams(): {}
OverlapParams(): {}
```

All three return an empty table currently. They don't perform a query and don't accept meaningful parameters.

```lua
local hits = PhysicsService:Raycast(origin, direction)
print(#hits) -- 0
```

Use `Workspace:Raycast()` and the corresponding `Workspace` query methods instead. Don't build gameplay around these placeholders.

## Notes

- The service starts with a single `Default` group.
- Group names are case-sensitive.
- Changing a part's collision group takes effect on its next physics synchronization.
- An unregistered name currently falls back to the default collision layer.
