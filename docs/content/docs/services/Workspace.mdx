---
title: Workspace
description: Manage the active 2D or 3D scene, physics, camera, and spatial queries.
---

`Workspace` holds the active game scene. It renders 3D parts by default; set `Dimension` to `Enum.Dimension.D2` to render and simulate descendant `Part2D` objects instead.

If an object has a position in the world, it's usually parented to Workspace. Reparenting a part away from Workspace removes it from the simulated world. Rigid-body gravity is configured on each part through `Part.Gravity`.

## Getting started

```lua
local Workspace = game:GetService("Workspace")

local spawnPart = Workspace:FindFirstChild("SpawnPart")
if spawnPart then
    print("Spawn is at", spawnPart.Position)
end
```

## Properties

| Property | Type | Access | Default | Description |
| --- | --- | --- | --- | --- |
| `SimulatePhysics` | `boolean` | Read/write | `true` | Whether the world simulates. `AutoSimulate` is an alias. |
| `GlobalWind` | `Vector3` | Read/write | `Vector3.new(0, 0, 0)` | Wind force applied to cloth and other affected objects. |
| `FluidForces` | `boolean` | Read/write | `false` | Compatibility alias for `Aerodynamics.Enabled`. |
| `FallenPartsDestroyHeight` | `number` | Read/write | `-500` | Y position below which parts are destroyed. Clamped to -50000 through 50000. |
| `FallHeightEnabled` | `boolean` | Read/write | `true` | Whether parts are destroyed when they fall below the limit. |
| `CurrentCamera` | `Camera?` | Read/write | None until set | The camera used for rendering. |
| `Terrain` | `Terrain` | Read-only | The Terrain service | Shorthand for the `Terrain` service. |
| `Dimension` | `Enum.Dimension` | Read/write | `Enum.Dimension.D3` | Which dimension the world renders and simulates. |
| `Enable3dRendering` | `boolean` | Read/write | `true` | Whether 3D rendering is enabled. |
| `RenderCulling` | `boolean` | Read/write | `true` | Whether off-screen parts are culled from rendering. |
| `MaxDrawDistance` | `number` | Read/write | `0` | Maximum draw distance. |
| `LODDistance` | `number` | Read/write | `0` | Distance used for level-of-detail switching. |
| `DistributedGameTime` | `number` | Read-only | Accumulates | Time value maintained by the service. |
| `FinishedReplicating` | signal | Read-only | N/A | Fires when the client has received the initial world data. |

`GlobalWind` must contain finite components; setting it to a vector with `nan` or `inf` raises an error. `MaxDrawDistance` and `LODDistance` clamp negative values to `0`. `FallenPartsDestroyHeight` is clamped to its range rather than rejected, so a smaller value silently becomes `-50000`.

Turning `SimulatePhysics` off stops the simulation but keeps the world rendered. Cloth objects on screen switch to their preview pose while simulation is off, and switching it back on resumes from the current configuration.

### 2D scenes

```lua
workspace.Dimension = Enum.Dimension.D2
local level = Instance.new("World2D", workspace)
local physics = game:GetService("Workspace2D")
physics.Gravity = Vector2.new(0, 130)
```

Use Workspace2D for 2D gravity and raycasts. The 3D spatial query methods do not query 2D bodies.

### Camera

Assigning `CurrentCamera` takes a `Camera` and makes it the active camera. Only a `Camera` object is accepted; other values aren't applied.

```lua
local Workspace = game:GetService("Workspace")
local Camera = workspace.CurrentCamera

if Camera then
    Camera.FieldOfView = 70
end
```

`Terrain` saves you a `GetService()` call when you're already working with the world:

```lua
local terrain = Workspace.Terrain
```

## Methods

### Raycast

```lua
Raycast(origin: Vector3, direction: Vector3, params: RaycastParams?): RaycastResult?
```

Casts a ray into the physics world and returns the first hit, or `nil` when nothing is hit. The optional `RaycastParams` filters which objects the query considers.

```lua
local function groundBelow(position)
    local result = workspace:Raycast(position, Vector3.new(0, -100, 0))
    if result then
        return result.Position, result.Instance
    end
    return nil
end
```

Use it for line-of-sight checks, ground detection, and placement previews. Because it goes through the physics world, it only sees objects that participate in physics and aren't filtered out by the parameters.

### Runtime queries

| Signature | Description |
| --- | --- |
| `GetNumAwakeParts(): number` | Number of physics bodies currently awake. |
| `GetRealPhysicsFPS(): number` | Currently always returns `60`. |
| `GetPhysicsThrottling(): number` | Currently always returns `0`. |
| `PGSIsEnabled(): boolean` | Currently always returns `true`. |
| `GetWindowDimensions(): Vector2` | Drawable window size in UI units, excluding safe-area insets. |
| `Enable3D(): ()` | Turns 3D rendering on. |
| `Disable3D(): ()` | Turns 3D rendering off. |

`GetRealPhysicsFPS()` and `GetPhysicsThrottling()` are placeholders, so don't use them to profile frame timings. Measure with `RunService` instead.

`GetWindowDimensions()` exists on the object but isn't listed in the class's reflection metadata. It's still callable.

## Events

### FinishedReplicating

Fires on the client once the initial world data has arrived. The callback receives no arguments.

```lua
workspace.FinishedReplicating:Connect(function()
    print("World is ready")
end)
```

If the event fires before you connect, your callback won't run. Treat it as a one-time readiness notification rather than a persistent state query, and check the objects you need with `FindFirstChild()`.

## Overlap queries and joining parts

| Method | Description |
| --- | --- |
| `GetPartBoundsInBox(frame: CFrame, size: Vector3, params: OverlapParams?): {BasePart}` | Returns intersecting part bounds for an oriented box. |
| `GetPartBoundsInRadius(position: Vector3, radius: number, params: OverlapParams?): {BasePart}` | Returns part bounds intersecting a sphere. |
| `GetPartsInPart(part: BasePart, params: OverlapParams?): {BasePart}` | Returns overlapping collision shapes, excluding the queried part. The part must belong to this Workspace. |
| `JoinToOutsiders(parts: {BasePart}, mode: Enum.JointCreationMode?): ()` | Joins eligible contacting parts outside the selected set; defaults to `Enum.JointCreationMode.All`. |
| `UnjoinFromOutsiders(parts: {BasePart}): ()` | Removes applicable welds between the selection and other parts. |

Box sizes and radii must be finite and nonnegative. Pass `OverlapParams` to filter results. The bounds queries use part bounds rather than exact collision geometry.
