---
title: AsepriteService
description: Convert Aseprite sprites and animation frames into ImageLabel instances.
---

`AsepriteService` decodes binary `.ase` and `.aseprite` files using the engine's built-in parser. Aseprite does not need to be installed.

## Methods

```lua
CreateImageLabel(source: buffer | string | Image, frameIndex: number?): (ImageLabel, number)
CreateImageLabels(source: buffer | string | Image): ({ImageLabel}, SpriteInfo, Image)
CreateImage(source: buffer | string | Image): (Image, SpriteInfo)
GetInfo(source: buffer | string | Image): SpriteInfo
```

Source may be an Image handle, a Luau buffer, a binary string, an embedded asset URI, or a `project://` asset URI. Arbitrary filesystem paths are not supported. Frame indices start at 1, and durations are in seconds.

```lua
local service = game:GetService("AsepriteService")
local label, duration = service:CreateImageLabel("project://sprites/player.aseprite")
label.Parent = script.Parent
label.Size = UDim2.fromOffset(128, 128)
```

Generated labels are unparented, have the original canvas dimensions, transparent backgrounds, and nearest-neighbor filtering. Textures use embedded PNG assets, so the normal project serializer can include them when saving a scene that references them.

## Animation

Use an `Image` instance to play the entire sprite automatically:

```lua
local animated, info = service:CreateImage("project://sprites/player.aseprite")
local sprite = Instance.new("ImageLabel")
sprite.Image = animated
sprite.ResampleMode = Enum.ResampleMode.Nearest
sprite.BackgroundTransparency = 1
sprite.Size = UDim2.fromOffset(info.Size.X, info.Size.Y)
sprite.Parent = script.Parent
```

`CreateImageLabels` retains its original first two return values and returns the complete animation as a third value. For automatic playback only, use `CreateImage` to avoid constructing individual frame labels.

## SpriteInfo

- `Size`: Vector2 containing canvas width and height.
- `FrameCount`: Number of frames.
- `Durations`: Array of frame durations in seconds.
- `Layers`: Array of layer names.
- `Tags`: Array of tables with Name, FromFrame, ToFrame, Direction, and Repeat. Both frame indices are 1-based; Direction is Forward, Reverse, PingPong, or PingPongReverse.

## Limitations

Imports are synchronous. Imports support normal compositing of RGBA, grayscale, and indexed sprites, including linked and compressed cels. Non-normal blend modes are treated as normal; tilemap cels and color profile transformations are not supported. `Image` playback loops through all frames in file order; animation tags are metadata, not playback controls. Resource limits include a 32 MiB source, 4096 pixels per canvas axis, 1024 frames, 16 million total canvas pixels, and 64 MiB of decoded cel data. Project file reads aren't available in browser builds; use buffers or embedded assets.
