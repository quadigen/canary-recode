---
title: LocalizationService
description: Load translation dictionaries and switch the language of your UI.
---

Use `LocalizationService` to translate text in labels and buttons without changing their original `Text` properties.

## Getting started

Create a JSON file called `fr-fr.json`:

```json
{
  "Play": "Jouer",
  "Settings": "Paramètres"
}
```

Load the dictionary from an embedded asset or pass its JSON directly.

```lua
local LocalizationService = game:GetService("LocalizationService")
assert(LocalizationService:LoadTranslations("fr-fr", [[
{"Play":"Jouer","Settings":"Paramètres"}
]]))
LocalizationService:SetLocale("fr-fr")

local label = Instance.new("TextLabel")
label.Text = "Play"
print(label.Text) -- Play (displayed as Jouer)
```

## Properties

| Property | Type | Access | Default |
| --- | --- | --- | --- |
| `RobloxLocaleId` | string | Read-only | `en-us` |
| `SystemLocaleId` | string | Read-only | `en-us` |

The system locale initially defaults to English rather than detecting the OS language.

## Methods

### SetLocale

```lua
SetLocale(locale: string, systemLocale: string?): ()
```

Selects the dictionary to display. Locale names are normalized to lowercase. An empty locale raises an error. The optional system locale changes the reported system identifier.

### LoadTranslations

```lua
LoadTranslations(locale: string, source: string): boolean
```

Loads a JSON object containing source strings and their translations. A successful load replaces the previous dictionary for that locale. Invalid JSON or non-string values return false without replacing it.

### LoadTranslationFile

```lua
LoadTranslationFile(locale: string, path: string): boolean
```

Loads the same JSON format from an embedded asset URI or a local file. Local filesystem access requires Internals capability. Returns false if the file cannot be read or the dictionary is invalid.

### Translate

```lua
Translate(source: string): string
```

Returns the matching translation for the current locale, or the original string when no entry exists.

## Notes

Matching is exact and case-sensitive for source strings. Labels and buttons update when you switch languages; editable text boxes are not translated. Dictionaries are held for the current session. There is no automatic translation, pluralization, or platform locale detection.
