---
title: Workspace2D
description: Configure gravity and query the shared 2D physics world.
---

`Workspace2D` owns the simulation for 2D scenes. Set `workspace.Dimension` to `Enum.Dimension.D2`, then parent the parts to Workspace. Get the service to change gravity or cast rays.

## Getting started

```lua
workspace.Dimension = Enum.Dimension.D2
local physics = game:GetService("Workspace2D")
physics.Gravity = Vector2.new(0, 300)
```

## Properties

| Property | Type | Access | Default | Description |
| --- | --- | --- | --- | --- |
| `Gravity` | Vector2 | Read/write | Vector2.new(0, 130) | Acceleration in logical pixels per second squared. |
| `BodyCount` | number | Read-only | 0 | Number of registered 2D bodies. |
| `ViewportSize` | Vector2 | Read-only | Vector2.new(1280, 720) before measurement | Logical dimensions used to resolve scaled positions and sizes. |

The simulation advances in fixed 1/60-second steps, independently of drawing. Set `workspace.SimulatePhysics` to false to pause without hiding the scene. Switching to D3 removes the 2D bodies. Switching back rebuilds them.

## Methods

### Raycast

```lua
Raycast(origin: Vector2, direction: Vector2): RaycastResult2D?
```

The direction length sets the maximum distance. Returns nil if nothing is hit or the world has not been initialized.

The result is a read-only table containing `Instance: Part2D`, `Position: Vector2`, `Normal: Vector2`, and `Distance: number`.

```lua
local hit = physics:Raycast(Vector2.new(200, 0), Vector2.new(0, 500))
if hit then
    print(hit.Instance.Name, hit.Distance)
end
```

Non-colliding parts are excluded. Results describe the most recent synchronized simulation state.
