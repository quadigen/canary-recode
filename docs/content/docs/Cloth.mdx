---
title: Cloth
description: Simulate curtains, flags, capes, and other deformable fabric with configurable meshes and attachment points.
---

`Cloth` is a Workspace instance that deforms under gravity, wind, and forces. Its simulation grid supports independent attachment constraints. Cloth uses a double-sided Filament mesh with smooth normals, shadows, material variants, and deforming front and back decals.

## Make a folded curtain

Create three `Attachment` instances named `Left`, `Center`, and `Right` under a rail in Workspace. Space the outer attachments about 7.8 studs apart for the dimensions below. The curtain uses folded rest geometry, including structural, shear, and bending constraints at the folds.

```lua
local rail = workspace.Rail
local cloth = Instance.new("Cloth")

cloth.ClothType = Enum.ClothType.Curtain
cloth.Size = Vector2.new(12, 8)
cloth.SegmentsX = 48
cloth.SegmentsY = 24
cloth.FoldCount = 8
cloth.FoldDepth = 0.35
cloth.FoldStiffness = 0.7
cloth.GatherRatio = 0.65
cloth.Color = Color3.fromRGB(145, 15, 25)
cloth.MaterialVariant = "Velvet"
cloth.Mass = 2
cloth.Damping = 3
cloth.CanCollide = true
cloth.SelfCollision = true

cloth:ClearPins()
cloth:PinPoint(Vector2.new(0, 0), rail.Left)
cloth:PinPoint(Vector2.new(0.5, 0), rail.Center)
cloth:PinPoint(Vector2.new(1, 0), rail.Right)
cloth.Parent = workspace
```

Set `MaterialVariant` to the name of a variant in your project. To hold the entire folded top edge, leave `CustomPins` off and assign the rail ends to `Attachment0` and `Attachment1`. Increase `SegmentsX` for more detail across the folds. The rest profile uses roughly three or more segments per fold on grids with at least three columns.

## Presets

| `Enum.ClothType` | Starting shape and attachment layout |
| --- | --- |
| `Flat` | Rectangular sheet. One attachment holds the top center and two attachments hold the upper corners. |
| `Curtain` | Gathered sheet with vertical folds. The preset holds the folded top edge. |
| `Flag` | Sheet pinned along the left edge. Two attachments define the top and bottom of that edge. |
| `Hammock` | Horizontal spans with a sag in the middle and pins along the two short edges. |
| `Cape` | Sheet pinned across the shoulders along its top edge. |
| `Custom` | Rectangular sheet with an open attachment layout. |

Preset anchors use `Attachment0` and `Attachment1`. On a two-anchor Flat cloth, the distance between the attachments sets the width. Coincident endpoints fall back to `Size.X`. If `Attachment1` is unset and `Attachment0` has exactly one usable sibling attachment, Cloth can use that sibling as the second anchor. A Flat cloth starts once an anchor is present or custom pin mode is enabled. Other presets can start at the world origin before you assign their mounts.

## Attach and release fabric

Vertices use one-based row-major indices. The top left is vertex 1, the top right is `SegmentsX + 1`, and the bottom right is `GetVertexCount()`. UVs run from `(0, 0)` at the top left to `(1, 1)` at the bottom right.

Calling a pin or unpin method enables `CustomPins` and gives control of the attachment layout to that pin map. Set `CustomPins = false` to use the preset layout again. Pins follow their attachments as they move. Destroying an attachment releases its pins. Runtime pin edits preserve the live simulation pose, and removing the final pin lets the sheet fall freely.

```lua
-- Bind a top-edge band to a single moving attachment.
cloth:PinRegion(Vector2.new(0.2, 0), Vector2.new(0.8, 0), workspace.Rail.Center)

-- Release the nearest vertex at the center of that band.
cloth:UnpinPoint(Vector2.new(0.5, 0))
```

A region keeps its vertices at distinct offsets in the attachment's coordinate frame. Moving or rotating the attachment carries the whole patch. Use individual `PinPoint` or `PinVertex` calls to bring specific vertices to anchor positions.

## Properties

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `ClothType` | `Enum.ClothType` | `Flat` | Selects the rest shape and preset pin layout. |
| `Attachment0`, `Attachment1` | `Attachment?` | `nil` | Optional preset mounts in Workspace. |
| `CustomPins` | `boolean` | `false` | Uses the explicit per-vertex pin map. |
| `Size` | `Vector2` | `Vector2.new(6, 4)` | Width and height in studs, from 0.1 to 1024 per axis. |
| `SegmentsX`, `SegmentsY` | `number` | `10` | Integer simulation grid dimensions from 1 to 64 per axis. A 10×10 grid has 121 particles, 24×24 has 625, and 48×48 has 2401. |
| `RenderSegmentsX`, `RenderSegmentsY` | `number` | `0` | Render grid dimensions from 0 to 128 per axis. Zero follows the simulation grid on that axis. Extra samples refine rendering between simulation vertices. |
| `Color` | `Color3` | `Color3.new(0.85, 0.85, 0.85)` | Base fabric color. |
| `MaterialVariant` | `string` | `""` | Name of the fabric's material variant. |
| `Enabled` | `boolean` | `true` | Enables simulation and rendering. Disabling clears the simulated pose and pending impulses. |
| `CanCollide` | `boolean` | `true` | Enables collision against eligible rigid parts, terrain, and character colliders. |
| `SelfCollision` | `boolean` | `false` | Separates nearby nonadjacent particles of this cloth. Higher resolution improves coverage of thin folds. |
| `Mass` | `number` | `1` | Controls response to force, impulse, and compliant constraints. Must be finite and at least 0.001. |
| `Damping` | `number` | `2` | Rate of velocity damping. Must be finite and nonnegative. |
| `Force` | `Vector3` | `Vector3.zero` | Continuous force on the free fabric. Cloth also responds to `Workspace.GlobalWind`. |
| `SolverIterations` | `number` | `8` | Number of XPBD constraint iterations per substep, from 1 to 32. Distant local cloth without rigid collisions can use fewer iterations. |
| `StretchStiffness` | `number` | `1` | Strength of the horizontal and vertical structural constraints, from 0 to 1. |
| `ShearStiffness` | `number` | `1` | Strength of the diagonal constraints, from 0 to 1. |
| `BendStiffness` | `number` | `0.15` | Strength of bending constraints along the height of a fold and across flat cloth, from 0 to 1. |
| `FoldCount` | `number` | `6` for Curtain, `0` for Flat | Number of corrugations, from 0 to 32. The simulation grid limits the effective count. |
| `FoldDepth` | `number` | `0.25` for Curtain, `0` for Flat | Fold amplitude in studs, from 0 to 1024. |
| `FoldStiffness` | `number` | `0.6` | Strength of bending constraints across folds, from 0 to 1. |
| `GatherRatio` | `number` | `0.65` for Curtain, `0` for Flat | For Curtain, the fraction of width retained when the span comes from `Size.X`. Zero uses the full width. Legacy Flat cloth interprets the value as the fraction removed. |

Choose a preset before setting its fold properties. Changing the simulation dimensions, size, or rest shape rebuilds the pose. Existing custom pins remap by normalized coordinates when the simulation grid changes.

## Methods

| Method | Description |
| --- | --- |
| `PinVertex(index, attachment)` | Moves a vertex to an attachment and keeps it pinned there. |
| `PinPoint(uv, attachment)` | Pins the closest simulation vertex to a UV coordinate. |
| `PinRegion(minUV, maxUV, attachment)` | Pins vertices within inclusive UV bounds to attachment-relative offsets. Equal bounds on an axis select its closest row or column. |
| `UnpinVertex(index)`, `UnpinPoint(uv)` | Removes a pin by index or by nearest UV. |
| `ClearPins()` | Clears the pin map and enables custom pin mode. |
| `GetPins()` | Returns a sparse table of custom attachments keyed by vertex index. |
| `GetVertexCount()` | Returns `(SegmentsX + 1) * (SegmentsY + 1)`. |
| `GetVertexPosition(index)` | Returns a vertex's current world position. The cloth needs an initialized pose in Workspace. |
| `SetPinWeight(index, attachment, weight)` | Sets a pin's strength from 0 to 1. A new assignment preserves the initialized vertex's offset relative to the attachment. Zero removes the pin. |
| `GetPinWeight(index)` | Returns the custom pin weight, or zero for a vertex without a custom pin. |
| `ResetSimulation()` | Rebuilds the rest pose on the next update and clears pending impulses. Keeps the configuration and pin map. |
| `ApplyImpulse(impulse)` | Queues a one-time push from a finite `Vector3`. Multiple impulses before a step accumulate. |

### Contact and forces

`Touched` fires when a touch-enabled rigid part or character root begins contact with the cloth. For continuous motion, set `Force` or `Workspace.GlobalWind`. Set `Force` back to `Vector3.zero` to stop applying it.

```lua
cloth.Touched:Connect(function(part)
    if part.Name == "CurtainMover" then
        cloth:ApplyImpulse(Vector3.new(0, 3, 10))
    end
end)
```

## Editor

Select a Cloth in Explorer and click **Edit pins** in the viewport panel. Select an Attachment alongside the Cloth to assign it as the brush target. **Select** picks a vertex, and **Apply weight** assigns the entered weight to it. **Paint** applies the weight while dragging, and **Erase** releases pins within the brush radius. Press **Escape** or **Done** to leave the mode.

Set `ClothType` to `Curtain` and use the Inspector to change fold properties. **Preview / Reset** rebuilds the current rest shape so you can see the effect and start a new simulation.

## Saving and multiplayer

Projects save the cloth configuration, attachment references, and any offsets and weights. Clones start from their configured rest shape and remap pin references to matching attachments inside the cloned hierarchy. Live deformations and pending impulses are transient.

The server runs the solver and reliably sends the configuration. Clients interpolate quantized particle snapshots. Periodic reliable keyframes deliver the final pose when cloth stops moving. The transport uses Zstandard where both peers support it and compression saves enough bandwidth.

## Simulation cost

Rigid collisions add work per particle and self-collision adds neighbour queries. Start with a 24×24 cloth and increase resolution where the silhouette or folds need it. The independent render grid can add tessellation while keeping the physics grid smaller. Cloth uses a CPU solver with preallocated constraint buffers, distance-based iteration limits for local noncolliding cloth, and sleeping for settled cloth without active rigid queries.

The Vulkan GPUCompute service can batch kernels and read back buffers. Moving this solver to GPUCompute would also require a way to feed CPU-side rigid collisions and authoritative snapshots without adding a synchronous readback to each substep.
